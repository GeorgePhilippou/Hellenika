# Knossos pilot: what is needed before it can be written

Goal: bring Knossos to the `standard: full` level (see `editorial-content-standard.md`).
Status: **blocked on source access.** The session that built Phase 1 could reach only
ancientcyprus.com, so no Knossos fact has been added. Nothing is written from memory.
